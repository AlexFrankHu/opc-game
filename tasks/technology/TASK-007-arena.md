**项目**：Last Bastion  
**模块**：Arena 竞技场  
**优先级**：P0  
**状态**：待开始  
**依赖**：TASK-002（战斗引擎）、TASK-003（Survivor 系统）

---

## 目标

实现基础 PVP 竞技场，提供每日挑战、排行榜和奖励体系，驱动玩家长期留存。

---

## 任务清单

### 7.1 匹配系统
- [ ] 基于战力区间的对手池（战力 ±15% 范围内匹配）
- [ ] 从排名高于自己的玩家中随机抽取 3 个对手
- [ ] 对手使用其防守队伍（离线状态下 AI 控制）

### 7.2 挑战机制
- [ ] 每日免费挑战次数：5次
- [ ] 购买额外次数：消耗 Premium Chips（每次 30 Chips，每日上限 10 次购买）
- [ ] 挑战次数每日 0 点重置
- [ ] 挑战结果：胜→双方排名交换（若挑战者排名低于被挑战者）；负→排名不变

### 7.3 排行榜
- [ ] 全服实时排行榜（按 Arena 段位分数）
- [ ] 玩家当前排名与分数显示
- [ ] 排行榜前 100 名展示队伍信息
- [ ] 每日结算时排名奖励发放（Credits / Tech Cores / Recruit Tokens）

### 7.4 防守队伍
- [ ] 玩家可单独设置 Arena 防守阵容（5人）
- [ ] 防守阵容独立于主线阵容
- [ ] 默认使用当前主线阵容

### 7.5 战绩记录
- [ ] 最近 20 场战斗记录（胜/负/对手名/排名变化）

---

## 验收标准
- [ ] 匹配逻辑在 100 人测试环境中无死循环
- [ ] 每日次数重置准时（±1分钟误差内）
- [ ] 排行榜更新延迟 < 5秒
- [ ] 购买次数扣费与次数增加原子操作，不出现扣费不到账情况
