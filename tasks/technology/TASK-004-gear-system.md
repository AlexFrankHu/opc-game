# TASK-004 · Gear System 装备系统

**项目**：Last Bastion  
**模块**：装备系统  
**优先级**：P0  
**状态**：待开始  
**依赖**：TASK-003（Survivor 系统）  
**参考原体系**：`doc/策划数据文档/挂机策划案/` 装备锁定相关

---

## 目标

实现完整的装备获取、强化、分解、锁定和穿戴体系。

---

## 任务清单

### 4.1 装备数据结构
- [ ] 装备槽位：Weapon / Armor / Helmet / Boots / Accessory×2
- [ ] 品质分级：White / Green / Blue / Purple / Orange
- [ ] 主词条（固定）+ 副词条（随机，2~4条）
- [ ] 词条类型池：ATK% / DEF% / HP% / SPD / CRIT Rate / CRIT DMG / ACC / RES
- [ ] 装备等级上限：+20

### 4.2 装备强化
- [ ] 强化消耗：Alloy（线性递增）
- [ ] 强化成功率（+1~+12 100%，+13~+16 递减，+17~+20 需特殊材料）
- [ ] 强化失败处理（等级不降，仅消耗材料）
- [ ] 强化加成：每+5 有额外属性突破

### 4.3 装备分解
- [ ] 分解产出 Alloy（按品质）
- [ ] 批量分解接口（按品质阈值筛选）
- [ ] 锁定装备不可分解（见 4.4）

### 4.4 Gear Lock 装备锁定
- [ ] 单件锁定/解锁切换
- [ ] 锁定状态持久化
- [ ] 批量操作时自动跳过已锁定装备

### 4.5 装备穿戴
- [ ] 穿戴/卸下接口（绑定到指定 Survivor）
- [ ] 已穿戴装备不可被其他 Survivor 直接穿戴（需先卸下）
- [ ] 装备属性实时生效到 Survivor 属性面板

### 4.6 装备背包
- [ ] 背包容量上限（默认 200 格，可扩展）
- [ ] 排序接口（按品质/槽位/等级）
- [ ] 背包满提示与自动分解建议

---

## 验收标准
- [ ] 强化概率在 10000 次模拟中误差 < 1%
- [ ] 锁定装备在批量分解中 100% 不被误删
- [ ] 装备属性实时生效，不需重新登录
- [ ] 背包满时触发提示，不丢失装备
