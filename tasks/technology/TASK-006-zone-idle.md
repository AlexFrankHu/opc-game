## 任务清单

### 6.1 Zone 关卡数据结构
- [ ] Zone 章节配置表（章节ID / 名称 / 背景 / 推荐战力）

- [ ] 掉落表配置（装备/材料/货币概率）
- [ ] 首通奖励配置

### 6.2 推图主循环
- [ ] 自动扫荡当前关卡（无需操作）
- [ ] 关卡通关解锁下一关
- [ ] 未通关无法跳过（线性解锁）
- [ ] 已通关关卡可重复刷取
- [ ] 扫荡速度配置（正常/×2/×4，后两者 Battle Pass 解锁）

### 6.3 离线挂机收益

- [ ] 按当前关卡掉落率估算离线收益
- [ ] 离线收益展示弹窗（登录时触发）
- [ ] 看广告双倍收益接口（预留，供后续广告 SDK 对接）
