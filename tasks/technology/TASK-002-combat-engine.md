# TASK-002 · Combat Engine 战斗引擎

**项目**：Last Bastion  
**模块**：战斗引擎  
**优先级**：P0（MVP 核心，其他模块依赖此模块）  
**状态**：待开始  
**参考原体系**：`doc/策划数据文档/挂机策划案/战斗相关/`

---

## 目标

实现完整的自动战斗引擎，支持挂机推图和 Arena PVP 两种战斗场景。

---

## 任务清单

### 2.1 战斗主循环
- [ ] 回合/时间片推进机制（基于 opc-game 战斗逻辑迁移）
- [ ] 我方队伍 vs 敌方队伍自动出手顺序（速度属性决定）
- [ ] 战斗结束判定（全灭 / 回合上限）
- [ ] 战斗结果结算（胜/负/掉落/经验）
- [ ] 战斗日志记录（供回放或调试用）

### 2.2 伤害计算
- [ ] 基础物理伤害公式（攻击 - 防御）
- [ ] 暴击率 / 暴击倍率计算
- [ ] 闪避率计算
- [ ] 元素/属性克制加成（如有）
- [ ] 伤害浮动范围（±10%随机）

### 2.3 Ability 技能系统
- [ ] 技能数据结构（类型/冷却/消耗/效果列表）
- [ ] 主动技能触发条件（能量/冷却/被动触发）
- [ ] 被动技能常驻生效
- [ ] 技能效果执行器（伤害/治疗/增益/减益）
- [ ] 技能动画钩子接口（供 UI 层调用）

### 2.4 Status Effects 状态系统
- [ ] Buff/Debuff 数据结构（类型/持续回合/叠加规则）
- [ ] 常见状态实现：
  - 中毒（Poison）：每回合损血
  - 灼烧（Burn）：每回合损血+减防
  - 眩晕（Stun）：跳过行动
  - 护盾（Shield）：抵消伤害
  - 攻击强化（ATK Up）
  - 防御强化（DEF Up）
- [ ] 状态叠加上限规则
- [ ] 状态回合倒计时与自动清除

### 2.5 CC Immunity 免控机制
- [ ] 免控标签（某些 Survivor 或装备词条带有）
- [ ] 免控生效时跳过眩晕/沉默/冻结效果

### 2.6 BOSS Rage Mode 狂暴机制
- [ ] BOSS 血量阈值触发（50% / 25% 各一次）
- [ ] 狂暴后属性倍率提升（攻击×1.5，速度×1.2）
- [ ] 狂暴特殊技能解锁
- [ ] 狂暴动画钩子接口

### 2.7 战斗配置数据
- [ ] 敌方单位数据表（属性/技能/AI行为）
- [ ] 关卡怪物波次配置表（对接 Zone 模块）
- [ ] BOSS 数据表（含狂暴阈值配置）

---

## 验收标准
- [ ] 5v5 自动战斗可完整跑通，无报错
- [ ] 技能触发概率在 1000 场模拟中误差 < 1%
- [ ] 所有 Status Effect 在边界回合正确清除
- [ ] BOSS Rage Mode 在血量阈值精确触发
- [ ] 战斗结果与预期数值表一致（可提供测试用例）
