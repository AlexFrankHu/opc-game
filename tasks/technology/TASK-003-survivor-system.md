## 目标

实现 Survivor 英雄的完整数据结构、成长体系和招募系统。

---

## 任务清单

### 3.1 Survivor 数据结构
- [ ] 基础属性：HP / ATK / DEF / SPD / CRIT Rate / CRIT DMG
- [ ] 元素/职业标签（Warrior / Scout / Medic / Engineer 等）
- [ ] 稀有度分级：Common / Rare / Epic / Legendary
- [ ] 技能槽：主动技能×1 + 被动技能×2
- [ ] 装备槽：Weapon / Armor / Augment ×3

### 3.2 等级成长
- [ ] 经验值曲线配置表（基于 opc-game 原始数值迁移）
- [ ] 升级触发属性成长（线性 + 职业系数）
- [ ] 等级上限：初始 60 级，后期版本解锁更高上限
- [ ] 批量喂经验道具接口

### 3.3 星级进阶
- [ ] 星级范围：1星 ~ 6星
- [ ] 进阶材料：同名碎片（Survivor Shard）合成
- [ ] 每次进阶后属性倍率提升（×1.15 / ×1.25 / ×1.40 / ×1.60 / ×2.0）
- [ ] 进阶后技能强化效果解锁（星级门槛）

### 3.4 Ability 技能等级
- [ ] 技能升级消耗（Skill Book + Credits）
- [ ] 技能等级上限：10级
- [ ] 每级效果数值提升配置表

### 3.5 招募系统（Gacha）
- [ ] 单抽 / 十连抽接口
- [ ] 保底机制：80 抽必出 Legendary
- [ ] 招募消耗：Recruit Tokens（免费向）/ Premium Chips（付费向）
- [ ] 招募历史记录
- [ ] 碎片转化（重复英雄 → Survivor Shard）

### 3.6 Survivor 管理界面数据接口
- [ ] 英雄列表查询（按稀有度/职业/战力排序）
- [ ] 英雄详情数据接口
- [ ] 上阵队伍配置（最多 5 人）
- [ ] 战力计算公式（供排行榜使用）

## MVP 初始英雄配置
最少需完成 **20 个 Survivor** 的数据配置（5 Legendary / 7 Epic / 8 Rare），覆盖 4 个职业。

- [ ] 保底机制在模拟 10000 次招募中误差 < 0.5%
- [ ] 战力计算公式与策划表一致
