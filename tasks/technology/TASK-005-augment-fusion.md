# TASK-005 · Augment Fusion 芯片合成系统

**模块**：Augment Fusion（对应原体系宝石合成）  
**优先级**：P1  
**状态**：待开始  
**依赖**：TASK-003、TASK-004

---

## 目标

实现末日科技风格的「增强芯片」合成与镶嵌系统，替代原体系宝石合成。

---

## 任务清单

### 5.1 Augment 数据结构
- [ ] 芯片类型：ATK Chip / DEF Chip / HP Chip / SPD Chip / CRIT Chip
- [ ] 芯片星级：1星 ~ 6星
- [ ] 每星级属性数值配置表

### 5.2 合成规则
- [ ] 3个同类型同星级芯片 → 合成1个高一星级芯片
- [ ] 合成界面逻辑（选择/确认/结果展示）
- [ ] 批量合成接口（自动消耗库存合成至目标星级）

### 5.3 镶嵌系统
- [ ] Survivor 有 3 个 Augment 槽位
- [ ] 镶嵌/取出接口（取出消耗少量 Credits）
- [ ] 镶嵌后属性实时生效

### 5.4 Augment 背包
- [ ] 独立背包（默认 100 格）
- [ ] 按类型/星级排序

---

## 验收标准
- [ ] 合成规则执行正确，数量消耗无误
- [ ] 镶嵌属性实时生效
- [ ] 背包上限保护正常
